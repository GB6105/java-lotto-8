## 프리코스 3주차 - 로또

## 문제 분석하기

- 로또 번호의 숫자 범위는 1~45까지이다.  
  -> 숫자 범위를 1 ~45로 제한

- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.  
  -> 숫자의 중복은 허용하지 않음, 숫자 개수 6개로 제한

- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.  
  -> 구입 금액은 최소 1000원, 금액 단위는 1000원으로 제한
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - `Exception`이 아닌`IllegalArgumentException`,`IllegalStateException`등과 같은 명확한 유형을 처리한다.

## 도메인 구분하기

**기존 구분**

Lotto - 당첨 번호 관리  
RandomNumber - 번호 랜덤 생성 및 관리  
RandomNumbers - 여러 개의 RandomNumber 관리  
BonusNumber - 보너스 번호 관리  
Checker - 당첨 번호와 보너스 번호를 통한 랜덤 번호 결과  
LottoResult - 당첨 결과 관리

**최종 구분**

Lotto - 로또 값 관리 (당첨 번호 비교)  
Lottos - 여러 개의 로또 값 관리  
WinningNumbers - 당첨 번호와 보너스 번호 관리  
LottoResult - 당첨 결과에 대한 관리

## 기능 구현 목록

**입력 기능**

- [X]  로또 가격 입력 받기
    - [X]  최소 금액 1000원
    - [X]  최대 금액 100,000원
    - [X] 금액 단위는 1000원 단위
        - [X]  [예외] 1000원으로 나누어 떨어지지 않으면 재입력
        - [X] [예외] 금액이 범위 에 맞지 않으면 재입력
- [X]  당첨번호 입력 받기
    - [X]  값의 범위는 1~45
    - [X]  6개 숫자 입력 받기
    - [X]  구분자 쉼표(,)만 허용
        - [X]  [예외] 위 조건이 지켜지지 않으면 재입력
- [X]  보너스 번호 입력 받기
    - [X]  값의 범위는 1~45
    - [X]  1개 숫자 입력 받기
    - [X] [예외] 위 조건이 지켜 지지 않으면 재입력

**값 저장**

- [X] 당첨 번호 및 보너스 번호
    - [X] 당첨 번호 저장
    - [X] 보너스 번호 저장
- [X] 평가 결과 저장
    - [X] 로또 매칭 결과 저장
    - [X] 수익률 계산 결과 저장

**검증기능**

- [X]  단일 값 검증하기
    - [X] 금액 검증
        - [X]  값의 단위 1000원
        - [X]  값의 최소 ~ 최대 1000, 100000
    - [X] 당첨 번호, 보너스 번호 개별 검증
      - [X]  값의 범위 1 ~ 45
    - [X] [예외] 검증에 실패하면 예외 발생
- [X]  값 개수 검증
    - [X]  6개 입력
   - [X] [예외] 검증에 실패하면 예외 발생

**로또 관련 기능**

- [X] 로또 발행하기
    - [X] 입력 받은 금액으로 개수 계산
    - [X] 개수 만큼의 로또 번호 생성
    - [X] 로또 번호는 오름 차순으로 정렬
- [X]  당첨번호와 로또 비교하기
    - [X] 로또 번호와 당첨 번호, 보너스 번호 비교
        - [X]  3개 당첨 - 5등
        - [X]  4개 당첨 - 4등
        - [X]  5개 당첨 - 3등
        - [X]  5개 당첨 + 보너스 번호 일치 - 2등
        - [X]  6개 당첨 - 1등
- [X] 수익률 계산하기
    - [X] 비교 결과로 총 합계산
    - [X] 구매 금액으로 수익률 계산

**출력 기능**

- [X]  메시지 출력
- [X]  발행한 로또 출력
- [X]  비교 결과 출력
    - [X] 낮은 순위부터 출력
    - [X] 출력 양식에 따라 출력
- [X]  수익률 출력
